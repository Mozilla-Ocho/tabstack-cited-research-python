Ollama's web-search API returns an array of search result objects, with each object containing three distinct fields: `title` (string), `url` (string), and `content` (string) [1][2]. The `title` field provides the title of the web page, and the `url` field gives the web page's URL [1][2]. Crucially, the `content` field within each web search result contains a **relevant content snippet** from the web page, not the full page content [1][2][3]. For retrieving the **full content** of a specific web page, Ollama offers a separate `web_fetch` API, which explicitly returns "the main content of the web page" in its `content` field [1][2].
